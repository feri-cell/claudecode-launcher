Claude Launcher

Start a cloud workspace with Claude Code already installed. No download. No setup. Ready in a couple of minutes.

What is this?

Claude Launcher gives you a ready-to-use coding environment in your browser. It runs on a cloud computer (a GitHub Codespace), with Claude Code already installed and configured. You just sign in and start typing — no terminal installs, no PATH setup, no Windows or Mac headaches.

It's like having a fresh laptop with everything pre-configured, accessed through your web browser.

How it works

  1. Click "Launch Claude Code" below You'll be asked whether you have a GitHub account
  2. Sign in with GitHub (or create an account in 30 seconds) GitHub is free. You'll just need an email address.
  3. Wait ~2 minutes while your workspace boots You'll see a progress screen showing each step
  4. VS Code opens in the browser Type claude in the terminal to start coding
  5. Sign in to Anthropic when prompted This happens once, the first time you run Claude Code

What you need

Free GitHub account
Free 60 hours/month of cloud compute included. Used to run the workspace. Don't have one? You can create it during sign-in.
Paid Anthropic account
Required for Claude Code itself: Pro, Max, Team, Enterprise, or API credits. There's no free tier of Claude Code.
