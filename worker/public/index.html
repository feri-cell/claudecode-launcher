📡 Pull Live EDGAR Filings
This dashboard is wired straight to the MSC EDGAR enrichment Worker — no Python script, no manual import. Pick the regulations, start the crawl, and contacts (names, roles, websites, and pattern-guessed / scraped emails) stream in automatically. The first run does a full historical backfill; after that only new filings are pulled in.
1
Pick Regulations
Choose Reg A+ / D / S / 144A (or all). The Worker discovers every matching filing on SEC EDGAR since each form's start year.
2
Start the Crawl
A 1-minute cron advances discovery → company → officers → email finding in resumable, rate-limited ticks. Watch live progress.
3
Contacts Load Themselves
As officers + emails surface they flow into the table, lists, and outreach sequences — the same UI you already use.
⚠ EDGAR API not reachable — open the dashboard at its *.workers.dev URL so it can talk to the Worker.

How emails are found: domain resolved from the filing's website or an MX-validated guess from the company name; addresses are the 8 industry-standard patterns.
