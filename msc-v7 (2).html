📡 Import Live EDGAR Filings
SEC EDGAR does not allow direct browser access. Use the Python script to fetch filings, then import the CSV here. All filtering, list management, and email outreach will work with your real data.
1
Get the Script
Click "Get Script" in the toolbar. Downloads edgar_fetch.py — fetches all Reg A+, D, S, 144A filings since 2015.
2
Run It
In Terminal: cd ~/Downloads && python3 edgar_fetch.py
Or paste into Google Colab — no install needed.
3
Import Here
Click "Import CSV" above. Large files (32MB+) load without freezing — chunked parser handles up to 200k rows.
